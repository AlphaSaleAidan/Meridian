# Meridian Off-Page SEO Checklist

Complete these manually — they cannot be automated.

## Priority 1 — Directory Listings (Week 1)

These sites are heavily cited by ChatGPT and Perplexity when answering B2B software questions.

- [ ] **G2.com** — https://g2.com/products/new
  - Category: Restaurant Management Software → POS Analytics
  - Ask first 10 merchants to leave a review
  - G2 is one of the most cited B2B software sources by AI tools

- [ ] **Capterra** — https://www.capterra.com/vendors/sign-up
  - Free listing, premium placement optional
  - Category: POS Software → Analytics

- [ ] **GetApp** — https://www.getapp.com/resources/add-product/
  - Free listing (same parent company as Capterra)

- [ ] **Product Hunt** — https://www.producthunt.com/posts/new
  - Product Hunt posts appear frequently in Perplexity answers
  - Coordinate launch day for upvotes

- [ ] **AlternativeTo** — https://alternativeto.net/
  - Add Meridian as alternative to: Square Analytics, Toast Analytics, Shopify Analytics
