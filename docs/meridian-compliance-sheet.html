◉ Camera Analytics — Zero Biometrics

  • Anonymous foot traffic counting via bounding boxes
  • Heatmaps and dwell time from aggregate data only
  • No facial recognition, no individual tracking
  • No images or video stored — only numerical metrics
  • Merchant must accept Camera Consent before activation
  • Merchant must post visible signage (Law 25 requirement)
  • Fully outside scope of CAI biometric enforcement

◉ CASL Email Enforcement

  • Programmatic consent check on every commercial email
  • Express consent recorded with SHA-256 evidence trail
  • Implied consent expires after 2 years automatically
  • Unsubscribe processed immediately (CASL: 10 business days)
  • 9 commercial + 11 transactional email types classified
  • Consent records retained 3 years for CASL audit
  • Working unsubscribe link in all commercial emails

Technical Security Controls

◉ Access & Encryption

  • Row-Level Security on all 85+ Supabase tables
  • Role-based access: admin, sales_rep, customer, owner
  • Portal context isolation (US / Canada data separation)
  • TLS 1.3 on all endpoints and database connections
  • AES-256 encryption at rest (Supabase managed)
  • Fernet (AES-128-CBC) for POS credentials and tokens
  • bcrypt password hashing with per-user salt

◉ Application Security

  • Pydantic input validation on all API endpoints
  • HTML sanitization on all user-submitted text
  • CORS locked to 7 known Meridian domains
  • Rate limiting middleware on all routes
  • Security headers: HSTS, CSP, X-Frame-Options
  • JWT-based auth (no cookie CSRF vector)
  • Local LLM inference: no merchant data leaves server

Key Takeaway for Investors

Compliance is not bolted on after the fact — it is embedded in Meridian's database schema, API layer, and frontend consent flows. Every commercial email is gated by CASL consent checks. Every privacy request is tracked to a 30-day deadline. Every document acceptance creates a cryptographic proof record. The camera analytics system was designed from day one to collect zero biometric data, placing Meridian entirely outside the scope of Quebec's CAI biometric enforcement actions. With SOC 2 Type I targeted for Q4 2026, Meridian is positioned to enter enterprise sales with a credible security certification on the near-term horizon.
