# POS Integrations — Roadmap & Vendor Inventory

**The truth first:** only **Square, Clover, and Toast** are live integrations today (production code under `src/square/`, `src/clover/`, `src/toast/` equivalents). Everything else in this table is roadmap inventory — registry stubs, CSV-only fallbacks, or partner-gated candidates researched during the connector buildout. Registry source of truth: `src/services/pos_connectors/registry.py`. This table consolidates the former per-vendor status briefs in `docs/playbook/_status/pos/`.

Status legend: **LIVE** = shipped; **READY** = config valid, needs connect UI/polish; **NEEDS PARTNERSHIP** = credentials gated behind a partner program; **CSV ONLY** = no API path wired (often a vendor constraint); **OUTDATED CONFIG** = registry entry wrong vs. the real API; **UNCERTAIN** = unvalidated config or unclear vendor situation; **DEAD API** = endpoint no longer exists.
